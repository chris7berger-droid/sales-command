### High

- **A4** — **`invite-user` logs full magic-link `action_link` via the `linkData` object** (carry-over — fourth cycle)
  - `supabase/functions/invite-user/index.ts:128`
  - Evidence: `console.log("generateLink result:", { linkData, linkErr: linkErr?.message });`
  - `linkData.properties.action_link` is a one-click magic-link that authenticates the invitee (redirectTo=`https://salescommand.app`). Written to Supabase function logs on every invite; anyone with log-read access can claim the account before the legitimate invitee.
  - Spec: OWASP-ASVS V7.1.1, OWASP-ASVS V3.5.3, OWASP A09.
  - Fix: `console.log("generateLink result:", { hasLink: !!linkData?.properties?.action_link, linkErr: linkErr?.message });`

### Medium

- **A5** — **`stripe-webhook` logs full recipient email for every outbound receipt** (carry-over)
  - `supabase/functions/stripe-webhook/index.ts:49`
  - Evidence: `console.log("Email to", to, ":", res.status);`
  - Customer email address written to function logs on every payment-receipt send. PII in logs; searchable index of who's getting paid emails.
  - Spec: OWASP-ASVS V7.1.1, OWASP A09, GDPR Art. 5(1)(c).
  - Fix: `console.log("Email send status:", res.status);` — drop `to`.

- **A6** — **`invite-user` logs invitee + sender emails and names on every call** (carry-over)
  - `supabase/functions/invite-user/index.ts:88`
  - Evidence: `console.log("invite-user invoked", { email, name, teamMemberId, senderEmail, senderName });`
  - Every invite writes invitee email + name + inviter email + name to function logs. Same PII-in-logs class as A5; enumerable by anyone with Supabase log access. Combined with A4 (magic-link log two frames later), a log reader gets full account-takeover material.
  - Spec: OWASP-ASVS V7.1.1, OWASP A09, GDPR Art. 5(1)(c).
  - Fix: log only `{ hasEmail: !!email, teamMemberId }`.

- **A7** — **`send-proposal` logs recipient + rep emails on every send** (carry-over)
  - `supabase/functions/send-proposal/index.ts:139`
  - Evidence: `console.log("send-proposal invoked", { proposalId, recipientEmail, repEmail, proposalNumber });`
  - Same PII-in-logs pattern. Every proposal-send writes customer + rep emails.
  - Spec: OWASP-ASVS V7.1.1, OWASP A09.
  - Fix: log only `{ proposalId, proposalNumber, hasRecipient: !!recipientEmail }`.

- **A8** — **`send-pay-app` logs recipient email on every invocation** (NEW)
  - `supabase/functions/send-pay-app/index.ts:99`
  - Evidence: `console.log("send-pay-app invoked", { payAppId, invoiceId, recipientEmail });`
  - Same class as A5/A6/A7 — customer email written to logs on every pay-app send. Not present in the 2026-08-03 findings for this file; the log line has been at line 99 through the sales-rep-notification refactor.
  - Spec: OWASP-ASVS V7.1.1, OWASP A09, GDPR Art. 5(1)(c).
  - Fix: `console.log("send-pay-app invoked", { payAppId, invoiceId, recipientDomain: recipientEmail?.split("@")[1] });`

- **A9** — **`_shared/repNotify.ts` logs sales-rep email on every successful send AND on every Resend failure** (NEW — introduced this cycle)
  - `supabase/functions/_shared/repNotify.ts:118`; also `:99`, `:115`, `:121`
  - Evidence: `console.log(\`${tag}: emailed ${to} — ${body}\`);` (`:118`) plus mirrored logs at `:99` (RESEND_API_KEY missing), `:115` (Resend non-2xx: logs status **and full response body**), `:121` (thrown).
  - New helper. Called from `proposal-approved`, `proposal-signed`, `follow-up-reminders` — every rep notification writes the rep's email + the full Resend response body (which includes the delivered message-id and can include recipient hints) to logs. The `:115` error branch pairs the rep email with the raw Resend body — same class as C10 for send-invoice.
  - Spec: OWASP-ASVS V7.1.1, OWASP A09, GDPR Art. 5(1)(c).
  - Fix: mask `to` in every log (`${to.slice(0,2)}***@${to.split("@")[1]}`) and drop the raw Resend body — log only `res.status` and Resend's returned `id`.

### Low

  - Evidence: `const SUPABASE_URL = import.meta.env.VITE_SUPABASE_URL || "https://pbgvgjjuhnpsumnowuym.supabase.co";`

  - Spec: OWASP-ASVS V14.3.2, OWASP A05.
