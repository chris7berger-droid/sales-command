- **A4** — **`invite-user` logs full magic-link `action_link` via the `linkData` object** (carry-over)
  - `supabase/functions/invite-user/index.ts:128`
  - Evidence: `console.log("generateLink result:", { linkData, linkErr: linkErr?.message });`
  - `linkData.properties.action_link` is a one-shot magic-link URL that signs the invitee in (redirectTo=`https://www.scmybiz.com`). Written to Supabase Edge function logs on every invite; anyone with log-read access can claim the account before the invitee. Carry-over from 2026-06-01/2026-06-28/2026-08-03 — fourth audit cycle in a row at the same line.
  - Spec: OWASP-ASVS V7.1.1, OWASP A09.
  - Fix: `console.log("generateLink result:", { hasLink: !!linkData?.properties?.action_link, linkErr: linkErr?.message });`

  - `src/lib/supabasePublic.js:16`

  - Fix: remove the literal; require the env var (throw on missing).

- **A6** — **`invite-user` logs invitee + sender emails and names on every call** (carry-over)

- **A9** — **Shared `repNotify.sendEmail` logs recipient email on every send + all three error branches** (NEW)
