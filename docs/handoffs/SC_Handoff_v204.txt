NEW BACKLOG ITEMS
-----------------
- B77 (T2, [Sev 6 · Like 6 · Eff half-day]) — password-reset & invite email LINKS are one-time-use
  and get PRE-CONSUMED by Microsoft/Outlook ATP "SafeLinks" (auth_logs show GET /verify from
  104.47.x / 209.51.8.x burning the token before the user clicks) -> user's real click gets
  "403 One-time token not found / link expired" -> the app ignores the resulting #error= hash and
  shows a bare sign-in screen (silent/confusing). ROBUST FIX = switch reset+invite off magic links
  to a typed 6-digit OTP (supabase.auth.verifyOtp({type:'recovery',...})) which scanners can't click.
  Interim also-worth-doing: surface "this link expired, request a new one" when the landing hash
  carries error=/otp_expired. NOTE: the reset-FORM-DETECTION half is ALREADY FIXED + live
  (2463370 + 93497a6); B77 is only the scanner/one-time-token reliability half. Affects INVITES too.
