before creating any branch, saved to personal memory.

DECISIONS (this session)
════════════════════════════════════════════════════════════════════════
  • Login-first app domains over a marketing splash: current users/preview links
    were forced through marketing. scmybiz.com/salescommand.app/*.vercel.app now go
    to /login (or the app if signed in); marketing lives on the existing sccmybiz.com
    host (SCC_HOST). Logged-in root already lands on Subcon Command Home. Chose this
    minimal change because a dedicated marketing domain already existed.
  • PW color reuses the crew scheduler's --pw (#6d28d9) and its prevailing_wage
    flag — no new PW functionality; purple removed from the general palette so
    purple always means PW across the app.
  • Bar readability: chose translucency (55% fill + fuller-color border) over
    darkening/thinning to calm the color mass while keeping bars distinct. Safe
    because bars now carry only a dark+teal chip, no white text.
  • Multi-week continuity: FIRST tried one-lane-across-all-rows (9198210) — it
    inflated busy weeks and produced a false "+1 more" (verified: Fri 9/25 had 4
    jobs, cap 4, but a lane sat empty). Switched to compact per-week packing +
    "shown in any row → shown in all rows" (1d74d69). Tradeoff: a spanning bar may
    occasionally sit on a different lane across the Sat→Sun break (slight vertical
    jump) rather than a perfectly straight line. Chris accepted this over false
    overflow.
  • Gap close: trim .app-main top padding for the calendar screen, NOT a negative
    margin (which clipped button tops against overflow:hidden).
  • Process: adopt a "Branch Assessment" before creating any branch (state base
    freshness + missing-commit collisions + options + a recommendation, Chris
    picks). Saved to personal memory. Born from branching off a 19-commit-stale
    local main earlier this session, which made the preview look like it had
    reverted the shipped calendar modernization.
